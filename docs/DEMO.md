# GalaxyMaps repeatable demo

## Preparation

Run `npm run build` and `npm start`, then open http://localhost:8787 in Chromium. `PORT=8788 npm start` selects this workspace's verification port. The first view is locked Earth. Documented layouts use 1440×900 desktop and 390×844 phone emulation. Close unrelated heavy tabs before presenting.

No account or API key is needed. Without Grok credentials, present the Guide as scripted catalog explanations. A localhost link is local; desktop rendering does not establish headset compatibility.

## Optional science and interaction checks

- **Earth → Mars:** Directions from Mars, origin Earth. Auto shows a calculated Hohmann transfer around 259 days (8.5 months) and a separate direct-distance speed benchmark. Travel choices are exactly Light speed and Voyager 1. Preview and Play time are separate and pause each other.
- **Universe:** choose Observable universe; show logarithmic scaling and distance bands, select a known galaxy and return locally. The boundary is not a wall or destination.
- **Gallery:** Saturn hero, arrows and Escape. Focus returns to its opener; sources/credits remain available.
- **Learning:** Sun → Guide → Explain this light delay. The scripted answer uses Earth/Sun separation/c, distinct from spacecraft duration. Unknown Andromeda internal depth gives Related recommendations without guessed physical nearness.
- **Sharing:** rotate/zoom, Share view, open the copied URL in a fresh tab on the same running machine. Object/layer/date/orientation restore. Denied clipboard access shows a selectable URL.
- **Saving:** save/unsave/Undo, open Saved & recently explored, reload/revisit. Storage stays in this browser.
- **Phone:** collapsed/half/full sheet, comparison, tour and sky. Sky zoom/recenter/Back paint above the sheet. Quiet retains a touch-accessible Restore controls button.

## Honest XR and integration status

WebXR includes spatial inspection, sourced text, related/tour Previous/Next, scaling/recenter and exit, with tested lifecycle ownership. Physical headset, visionOS Simulator, transient pinch, stereo comfort and performance are unverified. Follow the [secure-origin device checklist](polish/xr-status.md) before a headset demo. No public deployment URL exists here.

Delivered: 919 distinct objects, 374 featured destinations, 274 hero images, 479 gallery references, 68 galaxies, 21 Andromeda children and 109,389 HYG stars. Sources and actual results: [completion report](COMPLETION-REPORT.md).
