Backup B

Data and scientific integrity

Where numbers come from

  • JPL Horizons DE441 — Solar System vectors
  • SIMBAD — featured stars and deep sky
  • HYG v4.4 — 109,389 star positions
  • NASA fact sheets + exoplanet archive
  • Cited literature for key distances

What we will not fake

  • Parallax inverted only if σ/ϖ ≤ 20%
  • No routes to cosmological-redshift objects
  • Images labeled observed / illustration / AI
  • Milky Way disk is a reconstruction
  • Hohmann is idealized, not a launch plan

Earth → Mars

Idealized Hohmann transfer: about 259 days (8.5 months), with Δv, next window, and a separate straight-line benchmark.

Earth → Polaris

True 3D separation ≈ 433 ly. 433 years at light speed; about 7.7 million years at Voyager 1’s measured speed.

Backup C

Accessible paths and WebXR

Built toward WCAG 2.2 AA

  • Keyboard map: / search, H home, D directions, M voice
  • Skip links, live regions, ARIA combobox search
  • High contrast, larger text, reduced motion
  • Describe current view + nearby-object stepping
  • We do not claim ADA certification

WebXR on the same map

  • Enter VR from a user gesture when supported
  • Nearby linear scale; far objects log-compressed
  • Head gaze, pinch to fly, dwell to open details
  • Grok Voice starts with the session
  • Physical Vision Pro / Quest pass still pending

Backup D

Grok controls the map. It does not invent the sky.

What Grok actually does

  • Speech-to-speech over xAI realtime WebSocket
  • 5-minute client secret; API key never in the browser
  • Can search, route, tour, zoom, play time, share
  • Must quote tool-formatted distances and times
  • If the API is down: labeled offline scripted guide

SpaceX challenge, honestly

  • Built with Cursor
  • Uses Grok Voice (and Imagine, labeled AI reconstruction)
  • Uses real space / mission catalog data
  • No endorsement by SpaceX, xAI, NASA, or Google
